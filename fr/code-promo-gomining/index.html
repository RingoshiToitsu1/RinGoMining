Pourquoi le code vaut le coup : ce qu'est vraiment GoMining

GoMining exploite des installations de minage de Bitcoin dans le monde entier. Vous achetez une part de leur puissance de calcul, appelée térahash (TH), sous forme de mineur numérique, et elle vous rapporte des récompenses en Bitcoin chaque jour. Pas de machines chez vous, pas de facture d'électricité à votre nom.
