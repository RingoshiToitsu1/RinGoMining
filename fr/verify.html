Dernière étape. Votre ID me permet de confirmer que vous êtes inscrit avec RINGO5, puis je vous envoie votre bonus sous 24 heures.

    Trouvez votre ID GoMining

    Dans GoMining, touchez votre photo de profil (en haut à droite) pour ouvrir votre Profil. Votre ID est le numéro juste sous votre nom. Touchez l'icône de copie à côté.

  • 3
    Remplissez le formulaire ci-dessous

    Collez votre ID GoMining et les infos de votre portefeuille, puis validez.

Crypto de paiement
